# Track Plan: T4 Edge AI

## Specification
Integrate Gemini Nano via Google AI Edge SDK (AICore) to perform on-device symptom and environmental correlation to provide proactive health insights while maintaining the privacy-first mandate.

## Implementation Steps
- [x] Define `SymptomLog` and `EnvironmentalLog` Room entities in `core-data` and update `PhosDatabase`.
- [x] Add Google AI Edge SDK (AICore) dependencies to `core-intelligence/build.gradle.kts` and `app-phone/build.gradle.kts`.
- [x] Create `SymptomCorrelationEngine` in `core-intelligence` to construct prompts from local data and query Gemini Nano.
- [x] Implement `IntelligenceWorker` using WorkManager to run the correlation engine in the background (batch processing).
- [x] Update `app-phone` Dashboard/UI to display AI-driven insights generated by the `SymptomCorrelationEngine`.
- [x] Write unit tests for the prompt generation and correlation logic.

## Verification Plan
- Verify `SymptomLog` and `EnvironmentalLog` can be saved and retrieved from Room.
- Verify `IntelligenceWorker` successfully triggers and completes without errors.
- Verify Gemini Nano on-device inference executes properly via AICore (no network requests).
- Verify the phone dashboard accurately displays the generated insights.
